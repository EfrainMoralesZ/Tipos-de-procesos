# Versiones anteriores

Archivo histórico. **Nada de esta carpeta se usa ni se compila**; la versión activa es `ProcesosV4.py` en la raíz.

| Archivo | Qué era |
|---|---|
| `ProcesosV2.py` | Versión 2 de la app principal (tkinter). |
| `ProcesosV3.py` | Versión 3 de la app principal (tkinter). |
| `TiposDeProceso.spec` | Spec de PyInstaller que compilaba `ProcesosV3.py`. |

Estas versiones importan `Configurar`, `Dashboard`, `Editor_Codigos`, `Formato` y `Rutas` de la raíz, que ya se actualizaron para V4, así que no están pensadas para ejecutarse tal cual. Si necesitas una versión exacta, recupérala del historial de git.
